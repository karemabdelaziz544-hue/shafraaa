# 🌟 نظام إدارة محل شفرة (Shafra Retail Management System)

نظام متكامل لإدارة محلات التجزئة في جمهورية مصر العربية بالجنيه المصري (EGP / ج.م)، مصمم ومبني خصيصًا للمالك **كريم** لإدارة كافة تفاصيل المحل بفاعلية وسهولة تامة من الموبايل والكمبيوتر.

---

## 🚀 المواصفات الفنية (Tech Stack)

- **واجهة المستخدم:** Next.js 14 (App Router) + TypeScript + Tailwind CSS + shadcn/ui.
- **التصميم وتجربة الاستخدام:** عربي كامل (RTL)، خط Cairo / Tajawal، أزرار لمس عريضة، شريط سفلي للموبايل وقائمة جانبية لسطح المكتب، PWA جاهز للتثبيت كتطبيق على الهاتف.
- **قواعد البيانات والحماية:** Supabase (PostgreSQL + Auth + RLS). دعم العمل دون اتصال (Offline-first / Local fallback) مع مزامنة سحابية كاملة.
- **القواعد المحاسبية الصارمة:**
  - مبالغ مالية دقيقة `numeric(12,2)` لمنع أي أخطاء كسور.
  - الكاش ليس ربحاً: تكلفة وسعر بيع كل بند مخزنة بشكل دائم في بنود الفاتورة.
  - المصروفات الثابتة تخصم مرة واحدة فقط عند حساب صافي أرباح الفترة.
  - مسحوبات المالك ليست مصروفاً نهائياً ولا تخصم من الأرباح بل من النقدية.
  - معادلة المخزون: `رصيد أول + مشتريات - مبيعات + مرتجع سليم - توالف + تسويات معتمدة`.

## 🛠️ دليل تشغيل وتجربة كل شاشة خطوة بخطوة

### 1. الشاشة الرئيسية (Home)
- **الهدف:** رؤية أداء المحل اليومي الفوري في ثوانٍ.
- **ما تراه وتضغط عليه:**
  1. ترحيب مخصص: **"أهلًا يا كريم 👋"**.
  2. شريط المؤشرات الأربعة: مبيعات اليوم، مجمل الربح، مصروفات اليوم، ونقدية الدرج الحالية.
  3. شريط التنبيهات الذكية: ينبهك إذا كان هناك منتج وصل لحد الطلب، أو عميل تجاوز سقف الائتمان، أو مستحق لمورد.
  4. شبكة الوصول السريع: أزرار لمس كبيرة للانتقال المباشر.

### 2. نقطة البيع وفاتورة بيع جديدة (POS)
- **الرابط:** `/sales/new`
- **خطوات التجربة:**
  1. اضغط على أي صنف من الشبكة لإضافته للسلة، أو اضغط زر **"مسح الباركود بالكاميرا"**.
  2. عدل الكمية بالضغط على (+) أو (-) أو اكتب سعر بيع مخصص في خانة السعر.
  3. اختر العميل (أو اتركه "عميل نقدي").
  4. اختر طريقة السداد: **كاش**، **محفظة** (فودافون كاش)، **إنستاباي**، أو **آجل**.
  5. إذا كان البيع آجلًا، اكتب المبلغ المدفوع (مثلاً 50 ج.م من أصل 200 ج.م) -> سيقوم النظام تلقائيًا بحساب المتبقي كدين على العميل وتنبيهك إذا تجاوز حد الائتمان!
  6. اضغط **"إتمام وحفظ الفاتورة"** -> ستظهر لك نافذة الإيصال الحراري الجاهزة للطباعة فورًا، وسيتم خصم الكميات من المخزون وإيداع الكاش في الدرج.

### 3. المنتجات والتسعير وهامش الربح
- **الرابط:** `/products`
- **خطوات التجربة:**
  1. اضغط **"إضافة صنف جديد"**.
  2. اكتب الاسم، التكلفة، المصاريف الإضافية، وسعر البيع.
  3. لاحظ حساب **هامش الربح الفوري (%)** وقيمة الربح بالجنيه قبل الحفظ.
  4. استخدم زر **"النواقص فقط"** لتصفية الأصناف التي تحتاج لشراء عاجل.

### 4. العملاء والديون والائتمان
- **الرابط:** `/customers`
- **خطوات التجربة:**
  1. اعرض قائمة العملاء ومديونية كل عميل باللون الأحمر.
  2. اضغط **"كشف الحساب"** لمشاهدة سجل فواتير العميل وتواريخها.
  3. اضغط **"تحصيل دفعة"** لتسجيل سداد العميل لمبلغ نقدي أو عبر إنستاباي -> سيتم تقليل مديونيته وزيادة رصيد الدرج تلقائيًا.

### 5. الموردين وفواتير الشراء
- **الرابط:** `/suppliers`
- **خطوات التجربة:**
  1. اضغط **"فاتورة توريد"** عند استلام بضاعة جديدة من المورد.
  2. اختر الأصناف والكميات وسعر التكلفة الجديد.
  3. حدد المبلغ المسدد للمورد وطريقة السداد -> تضاف الكميات للمخزون فورًا ويُحدث سعر التكلفة بالمنتجات.
  4. اضغط **"سداد دفعة"** عند دفع مستحقات سابقة لمورد من الدرج.

### 6. المخزون وقيمة البضاعة والجرد الفعلي
- **الرابط:** `/inventory`
- **خطوات التجربة:**
  1. راقب إجمالي قيمة البضاعة بسعر التكلفة (رأس مالك المربوط في البضاعة).
  2. اضغط **"بدء جرد فعلي جديد"**.
  3. اكتب الأعداد الحقيقية الموجودة على الأرفف بالمحل -> يظهر لك النظام فورًا فارق العجز أو الزيادة بالقطع وبالجنيه.
  4. احفظ كمسودة، وعندما تتأكد اضغط **"اعتماد وتحديث المخزن"** لتسوية الأرصدة رسميًا.

### 7. المصروفات الثابتة والمتغيرة
- **الرابط:** `/expenses`
- **خطوات التجربة:**
  1. اضغط **"تسجيل مصروف جديد"**.
  2. اختر نوع المصروف: **ثابت** (إيجار، كهرباء، رواتب) أو **متغير** (أكياس، بوفيه، نقل).
  3. اختر طريقة الصرف نقدًا ليتم خصمها من الدرج اليومي.
  4. لاحظ أن المصروفات الثابتة تخصم مرة واحدة فقط في حساب أرباح الفترة.

### 8. تقفيل الدرج اليومي واليومية
- **الرابط:** `/drawer`
- **خطوات التجربة:**
  1. شاهد معادلة اليومية الدقيقة: `رصيد أول + الوارد كاش - المنصرف كاش = الرصيد المتوقع بالدرج`.
  2. لاحظ تتبع المحافظ الإلكترونية وإنستاباي بشكل منفصل تماماً عن نقدية الدرج الكاش.
  3. اضغط **"تقفيل اليومية وإغلاق الدرج"**.
  4. اكتب النقدية الفعلية بعد عد الفلوس في الدرج -> سيحسب النظام فوراً العجز أو الزيادة.
  5. بعد القفل يصبح الدرج مقفلًا ولا يمكن تعديله إلا من خلال زر المالك **"إعادة فتح"**.

### 9. التقارير وصافي الأرباح
- **الرابط:** `/reports`
- **خطوات التجربة:**
  1. اختر فترة التقرير: شهري أو سنوي.
  2. شاهد قائمة الدخل: إيراد المبيعات - تكلفة البضاعة المباعة = مجمل الربح - المصروفات = صافي الربح الفعلي.
  3. شاهد رسم بياني لمبيعات آخر 7 أيام وقائمة الأصناف الأكثر مبيعًا.
  4. اضغط **"تصدير إكسيل (XLSX)"** لتنزيل شيت مالي كامل، أو **"طباعة PDF"**.

### 10. إيرادات الخدمات ومسحوبات المالك
- **الخدمات (`/services`):** لتسجيل دخل خدمات إضافية بالمحل (نسخ مفاتيح، تصوير أوراق) دون خصم مخزون.
- **مسحوبات المالك (`/withdrawals`):** لتسجيل مسحوبات كريم الشخصية بالاسم والتاريخ والسبب؛ تُخصم من النقدية لكنها **لا تعتبر مصروفًا** في قائمة الأرباح.

### 11. استيراد شيتات الإكسيل الـ 24
- **الرابط:** `/import`
- **خطوات التجربة:**
  1. اضغط **"تحميل نموذج الإكسيل الفارغ"** للحصول على ملف نموذجي يحتوي على شيتات العمل الـ 24 بالعربية.
  2. ارفع ملف الإكسيل الخاص بك (.xlsx أو .xls).
  3. سيتعرف النظام تلقائيًا على الشيتات وأسمائها (المنتجات، العملاء، الموردين، المصروفات...).
  4. راجع ربط الأعمدة وعينة البيانات ثم اضغط **"تأكيد واستيراد"** أو **"استيراد كل الشيتات دفعة واحدة"**.

## ✨ تخصيص الحركات والأداء (Motion & Loading Config)

يعتمد النظام على ملف إعدادات موحد للحركات في [`src/lib/motion.ts`](file:///Users/karemabdelaziz/shifra/shafraaa/src/lib/motion.ts) مع التزام صارم بالأداء على الهواتف المتوسطة:
- **خصائص GPU فقط:** كافة الحركات تستخدم `transform` و `opacity` فقط دون أي تحريك للأبعاد (`width`/`height`).
- **سقف الزمن:** مدة كل حركة لا تتجاوز **300ms** (`0.14s` للأزرار والتوست، `0.19s` لانتقالات الصفحات المتوافقة مع RTL، `0.22s` للنوافذ والأدراج).
- **تعديل الإعدادات:** يمكنك تعديل الثوابت `MOTION_DURATIONS` و `MOTION_EASINGS` و `MOTION_DISTANCES` داخل [`src/lib/motion.ts`](file:///Users/karemabdelaziz/shifra/shafraaa/src/lib/motion.ts) لتغيير سرعة أو مسافة الحركات في التطبيق بالكامل دفعة واحدة.
- **احترام إمكانية الوصول:** يتعرف `MotionProvider` تلقائياً على تفضيل المتصفح `prefers-reduced-motion` ويعطل الحركات غير الضرورية.
